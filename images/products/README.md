# Product photos

Drop a JPG in this folder named after the product id and it appears in that
product's popup. Nothing else to change — no code edit, no data entry. A
product with no file here simply shows no photo.

    images/products/<id>.jpg

Shoot them square-ish, on a plain light background, around 800x800. The popup
letterboxes rather than crops, so a label never gets cut off.

## The ones worth photographing

78 products can carry a photo: these 28 off the shelf, plus the 50 peptide vials.
The other 58 items are treatments and visits, which have no product shot and never
ask for one.

Start with the 28 below — they are what a customer buys by looking at the bottle,
so a picture is what makes the sale. The peptide vials can wait, and may well be
one photo of the same vial used 50 times.

which images pulled off a search result are not.
